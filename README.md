# ExamSaathi API (backend)

Node / Express API for [ExamSaathi](https://github.com/Lokesh777/examshaathi-frontend_web).

## Quick start

```bash
cp .env.example .env   # fill MONGODB_URI, JWT_SECRET, GROQ_API_KEY, etc.
npm install
npm run dev
```
